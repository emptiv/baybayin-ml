# Image Classification with CNN 

An ongoing project that develops a **Convolutional Neural Network (CNN)** to classify **handwritten Baybayin characters**, contributing to the preservation of Filipino heritage scripts.  

## ✨ Features  
- Classification of handwritten Baybayin characters  
- Baseline model for handwriting recognition applications  
- High accuracy performance on character recognition tasks  

## 🚀 Tech Stack  
- **Language:** Python  
- **Frameworks:** TensorFlow, Keras  
- **Environment:** Jupyter Notebook  

## 🎯 Goals  
- Build a robust model for recognizing Baybayin characters  
- Provide a foundation for future handwriting recognition apps  
- Support cultural preservation through technology
